# 🚀 Быстрый старт

Этот документ поможет вам быстро запустить CRM систему с интеграцией МойСклад.

## ⚡ Быстрая установка

### 1. Клонирование и настройка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd crm

# Запустите скрипт настройки
chmod +x scripts/setup.sh
./scripts/setup.sh
```

### 2. Получение токена МойСклад

1. Войдите в [МойСклад](https://app.moysklad.ru)
2. Перейдите в **Настройки → API**
3. Создайте новый токен доступа
4. Скопируйте токен

### 3. Настройка токена

Отредактируйте файл `backend/.env`:

```bash
# Замените на ваш реальный токен
MOYSKLAD_TOKEN=ваш_токен_здесь
```

### 4. Запуск системы

```bash
# Запустите все сервисы
chmod +x scripts/dev.sh
./scripts/dev.sh
```

### 5. Применение миграций

```bash
# Примените миграции базы данных
docker-compose exec app-backend alembic upgrade head
```

## 🌐 Доступ к системе

После запуска система будет доступна по адресам:

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Documentation**: http://localhost:8000/docs

## 🔄 Первая синхронизация

Запустите синхронизацию данных из МойСклад:

```bash
curl -X POST http://localhost:8000/api/v1/connectors/moysklad/sync \
     -H 'Content-Type: application/json' \
     -d '{"sync_type": "full", "force": false}'
```

## 📊 Просмотр данных

1. Откройте http://localhost:3000
2. Нажмите "Синхронизировать" для загрузки данных
3. Просматривайте товары, клиентов и документы
4. Изучайте аналитику и прогнозы

## 🛠 Полезные команды

```bash
# Просмотр логов
docker-compose logs -f

# Остановка сервисов
docker-compose down

# Перезапуск сервисов
docker-compose restart

# Вход в контейнер backend
docker-compose exec app-backend bash

# Запуск тестов
./scripts/test.sh
```

## ❗ Важные замечания

- ⚠️ **НИКОГДА** не коммитьте реальные токены в репозиторий
- 🔒 Используйте сильные пароли для production
- 📊 Синхронизация может занять время при большом объеме данных
- 🐳 Убедитесь, что Docker и Docker Compose установлены

## 🆘 Проблемы?

Если что-то не работает:

1. Проверьте логи: `docker-compose logs`
2. Убедитесь, что токен МойСклад корректный
3. Проверьте, что все сервисы запущены: `docker-compose ps`
4. Создайте Issue с описанием проблемы
