# Contributing to CRM MoySklad Integration

Спасибо за интерес к проекту! Мы приветствуем вклад в развитие CRM системы.

## 🚀 Как начать

1. Форкните репозиторий
2. Создайте feature branch: `git checkout -b feature/amazing-feature`
3. Внесите изменения
4. Зафиксируйте изменения: `git commit -m 'Add amazing feature'`
5. Отправьте в branch: `git push origin feature/amazing-feature`
6. Создайте Pull Request

## 📋 Требования к коду

### Backend (Python)

- Используйте `black` для форматирования кода
- Используйте `isort` для сортировки импортов
- Используйте `ruff` для линтинга
- Используйте `mypy` для проверки типов
- Покрытие тестами должно быть не менее 80%

```bash
# Форматирование
black .
isort .

# Линтинг
ruff check .

# Проверка типов
mypy app/

# Тесты
pytest tests/ -v --cov=app
```

### Frontend (TypeScript/React)

- Используйте `prettier` для форматирования
- Используйте `eslint` для линтинга
- Покрытие тестами должно быть не менее 70%

```bash
# Форматирование
npm run format

# Линтинг
npm run lint

# Тесты
npm test
```

## 🧪 Тестирование

### Обязательные тесты

- Unit тесты для всех новых функций
- Integration тесты для API endpoints
- E2E тесты для критических пользовательских сценариев

### Запуск тестов

```bash
# Все тесты
./scripts/test.sh

# Только backend
cd backend && pytest tests/ -v

# Только frontend
cd frontend && npm test
```

## 📝 Документация

- Обновляйте README.md при добавлении новых функций
- Добавляйте docstrings для всех функций
- Обновляйте API документацию
- Добавляйте примеры использования

## 🔒 Безопасность

### ⚠️ КРИТИЧЕСКИ ВАЖНО

- **НИКОГДА** не коммитьте реальные токены или пароли
- Используйте `.env.example` файлы для шаблонов
- Все секреты должны быть в переменных окружения
- Проверяйте `.gitignore` перед коммитом

### Проверка безопасности

```bash
# Проверка на наличие секретов
grep -r "password\|token\|secret\|key" --exclude-dir=.git --exclude="*.md" .
```

## 🐛 Сообщения об ошибках

При создании Issue:

1. Используйте шаблон Issue
2. Опишите проблему подробно
3. Приложите логи (без токенов!)
4. Укажите версию и окружение
5. Добавьте шаги для воспроизведения

2. Обсудите с командой

- [ ] Код соответствует стандартам проекта

## 🏗 Архитектура

### Backend

- **FastAPI** - веб-фреймворк
- **SQLAlchemy** - ORM
- **Alembic** - миграции
- **Celery** - фоновые задачи
- **Redis** - кэширование и очереди

- **Tailwind CSS** - стили
